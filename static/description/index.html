Ribbon

A corner banner so a test database is not mistaken for production.

Where to configure

Settings → Technical → PNS Ribbon. Administrators only (the Settings group).

Text, colours, a live preview, and the last 20 colour pairs. The same values can be edited as system parameters (pns_ribbon.html, pns_ribbon.textColor, pns_ribbon.backgroundColor, pns_ribbon.enabled, pns_ribbon.shadow) under Settings → Technical → System Parameters.

What it is

Part of Patanegra Soft Suite. A diagonal banner on the backend (TEST, DEV, STAGING). The script and the stylesheet are plain files in the page head, so an OWL upgrade does not remove the banner.

Depends only on the Community module web.

What it does

  • Corner banner — one text, two colours, on every backend page.
  • Placeholders — {dbname}, {user}, {company}.
  • On / off — hide it without uninstalling.
  • Colour and opacity — picker, slider, or a pasted rgba().
  • Recent colours — the last 20 pairs, one click to reuse.
  • Shadow — optional, for a flatter look.

What it does not do

  • It does not block login, hide menus, or change access rights.
  • It does not edit business documents. It stores the banner as system parameters.
  • It does not translate the banner. One text for the whole database.

How to install

  1. Use the flat branch 14.0 or 19.0, or run install_flat.sh for that series.
  2. Put the module on the addons path, update the app list, and install Ribbon.
  3. Open Settings → Technical → PNS Ribbon and set the text.

Odoo versions

14.015.016.017.018.019.0

Coloured: tested, with a flat branch. Grey: coming soon. Odoo 13 and older are not supported: Patanegra Soft Suite starts where its AI can run (OWL for the chat, Python 3.7 for the engine).

Source code

On GitHub: patanegra-soft/pns_ribbon.

  • main is one tree for every series: shared code in common/ and one stack per OWL generation (owl1 for Odoo 14, owl2 for 15 and later). Clone it to maintain several Odoo versions from one place.
  • ./install_flat.sh 19.0 <dir> builds the flat module of a series. The branches 14.0 and 19.0 are that result, ready for the addons path.
  • Tests without a database (unit_tests/, pytest) live in main. Odoo tests are in the module's tests/.

Bugs: an issue, with the bug form. Ideas and questions: Discussions.
